# Amazon EC2 — Beginner to Practical Guide

Amazon EC2 provides virtual servers, called instances, in the AWS cloud.

This section explains how to launch, connect, secure, manage and
troubleshoot EC2 instances.

## Learning Outcomes

After completing this section, students should be able to:

- Explain EC2 and its use cases
- Select an appropriate instance type
- Launch an EC2 instance
- Connect to a Linux instance using SSH
- Configure security groups
- Understand EC2 pricing options
- Create and use AMIs
- Use Elastic IP addresses
- Automate instance setup using user data
- Troubleshoot common connection problems

## Important Cost Warning

Always check current AWS pricing and Free Tier eligibility before
creating resources. Stop or terminate unused instances and remove
unused chargeable resources.

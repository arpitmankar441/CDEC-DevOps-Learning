## 🔐 Learning Safety Rules

- Never commit passwords, API keys, tokens, or private keys.
- Never copy credentials from another repository.
- Use `.gitignore` for local secret and environment files.
- Restrict cloud firewall and Security Group rules.
- Avoid `chmod 777` as a permission solution.
- Review commands before running them with `sudo`.
- Use disposable resources for experiments.
- Check pricing before enabling cloud or monitoring services.
- Remove resources after completing a lab.
- Sanitize screenshots and logs before sharing them.

# 🔧 Git & GitHub Fundamentals

Welcome to the **Git & GitHub** section.

Git is one of the most important tools for DevOps engineers because it is used for:

- Version control
- Collaboration
- Source code management
- Tracking changes
- Branching
- Merging
- CI/CD workflows

GitHub is a platform used to store Git repositories and collaborate with other developers.

# 7. Git Basic Workflow

The basic Git workflow is:

```text
Working Directory
       ↓
   git add
       ↓
Staging Area
       ↓
  git commit
       ↓
Local Repository
       ↓
   git push
       ↓
GitHub Repository
```
